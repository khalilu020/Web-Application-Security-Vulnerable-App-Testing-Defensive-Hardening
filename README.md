# Web-Application-Security-Vulnerable-App-Testing-Defensive-Hardening
Hands-on web application security testing project using OWASP DVWA in an isolated lab. I found and exploited real vulnerabilities (SQL Injection, XSS, weak authentication, file inclusion), fixed the actual source code, and built custom Wazuh SIEM rules to detect the same attacks — with a full pentest-style report.
